# Project Description for DigitalOcean

## **What I'm Building**
I'm working on a research project to study how online shopping works in Indonesia. Think of it like a smart tool that helps understand e-commerce trends and pricing patterns on websites like Tokopedia and Shopee.

## **Why This Project Matters**
As a researcher, I'm trying to answer questions like:
- How do prices change over time on different platforms?
- What products are trending in Indonesian e-commerce?
- How do different websites organize their product catalogs?
- What can we learn about digital shopping behavior?

This isn't for making money - it's pure research to understand how online markets work in Southeast Asia.

## **How It Works**
My tool visits e-commerce websites (just like a person browsing would), looks at product pages, and collects public information like:
- Product names and descriptions
- Prices and availability
- Category structures
- How pagination works on different sites

Then I use machine learning to find patterns and trends in this data.

## **Technical Setup**
- **Language**: Python (it's what I know best for data analysis)
- **Database**: MongoDB to store the research data
- **Deployment**: Using Dokploy because it makes managing the app easier
- **Browser**: Chrome in headless mode for visiting websites
- **Hosting**: Need a reliable VPS that can run 24/7 for consistent data collection

## **Why I Need a VPS**
- **Consistent data collection**: Need to check websites regularly to track changes
- **Processing power**: Machine learning requires decent CPU and memory
- **Storage**: Research data grows over time and needs reliable storage
- **Uptime**: Academic research needs consistent, uninterrupted data collection

## **Being Respectful**
I'm very careful about how I collect data:
- I follow robots.txt files and website rules
- I add delays between requests so I don't overload servers
- I only collect publicly available information
- I identify myself properly in requests
- I respect rate limits and back off if websites seem busy

## **What I'm NOT Doing**
- Not collecting personal information or user data
- Not trying to break into accounts or bypass security
- Not selling or redistributing the data commercially
- Not overwhelming websites with too many requests
- Not violating any terms of service

## **Expected Usage**
- **CPU**: Moderate usage for web browsing and data processing
- **Memory**: About 4-8GB for browser and machine learning operations
- **Storage**: Growing dataset, probably 50-100GB over time
- **Network**: Regular but respectful web requests, not heavy bandwidth

## **Research Goals**
I plan to publish my findings in academic papers and maybe create open-source tools for other researchers studying e-commerce. The goal is to better understand how digital markets work in developing economies.
