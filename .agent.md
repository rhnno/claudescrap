# Enhanced ML-Powered Web Scraper - Developer Guide

## Project Overview

### Purpose
E-Commerce Market Intelligence Platform (EMIP) - An advanced web scraping system with ML-powered pagination detection for Indonesian e-commerce sites (Tokopedia, Shopee, Bukalapak). Designed for academic research and market intelligence gathering.

### Technology Stack
- **Language**: Python 3.8+
- **Web Automation**: Selenium WebDriver 4.15.2
- **ML Framework**: Scikit-learn 1.3.2
- **Data Processing**: Pandas 2.1.4, NumPy 1.24.3
- **Configuration**: YAML (PyYAML 6.0.1)
- **Storage**: CSV, Excel (openpyxl), MongoDB (optional)

### Key Features
- ML-powered pagination detection with 50+ features
- YAML-configurable site templates
- Chrome profile management with session persistence
- Real-time bug scanning and monitoring
- Multi-site support with intelligent navigation
- Production-ready batch processing

## Project Structure

### Core Directories
- `func/` - Core functionality modules
- `config/` - YAML configuration files and templates
- `models/` - ML models and training data
- `data/` - Scraped data (raw_html/, processed/)
- `logs/` - Application logs
- `chrome_profiles/` - Browser profile storage

### Important Files

#### Main Scripts
- `main.py` - Legacy main scraper entry point
- `enhanced_tokoscrape.py` - Enhanced scraper with ML integration
- `train_model_orchestrator.py` - Automated ML model training
- `scraping_orchestrator.py` - Production batch scraping
- `integrated_system_manager.py` - Unified system management

#### Core Modules (`func/`)
- `analyzer.py` - ML-powered pagination analyzer (ConfigurableAnalyzer, EnhancedConfigurableAnalyzer)
- `browser.py` - Browser management with anti-detection (BrowserManager)
- `storage.py` - Data storage utilities (DataStorage)
- `utils.py` - Random utilities and helpers (RandomUtils)

#### Configuration Files
- `config/analyzer_config.yaml` - Analyzer settings and thresholds
- `config/enhanced_training_templates.yaml` - Site-specific ML templates
- `scraping_config.json` - Batch scraping configuration
- `config/login_credentials.json` - Encrypted login credentials

#### System Management
- `enhanced_chrome_profile_setup.py` - Chrome profile setup with manual login
- `continuous_bug_scanner.py` - Real-time monitoring and error detection
- `verify_integrated_systems.py` - System verification and testing

## Development Guidelines

### Code Style and Conventions
- Follow PEP 8 Python style guidelines
- Use type hints for better code clarity
- Document all classes and methods with docstrings
- Use snake_case for functions and variables
- Use PascalCase for class names
- Prefix temporary files with `tmp_rovodev_`

### Error Handling
- Implement comprehensive exception handling
- Use logging instead of print statements for production code
- Provide meaningful error messages with suggestions
- Include fallback strategies for critical operations

### Configuration Management
- Store all configurable parameters in YAML files
- Use site-specific templates for different e-commerce platforms
- Separate development and production configurations
- Validate configuration files on startup

### Browser Management
- Always use BrowserManager class for browser operations
- Include headless parameter: `BrowserManager(headless=False)`
- Implement anti-detection measures
- Use persistent Chrome profiles for session management
- Handle browser crashes and timeouts gracefully

### ML Model Development
- Use EnhancedConfigurableAnalyzer for pagination detection
- Extract 50+ features per page for better accuracy
- Implement weighted confidence scoring
- Store models in `models/` directory with versioning
- Include model validation and performance metrics

## Best Practices

### Scraping Ethics
- Respect robots.txt and rate limits
- Use random delays between requests
- Implement proper session management
- Monitor for IP blocking and implement rotation
- Only scrape publicly available data

### Performance Optimization
- Use headless mode for production scraping
- Implement connection pooling and reuse
- Cache frequently accessed data
- Monitor memory usage and implement cleanup
- Use batch processing for large-scale operations

### Testing and Validation
- Run `verify_integrated_systems.py` before deployment
- Test with mock drivers for unit testing
- Validate YAML configurations on changes
- Monitor system health with continuous bug scanner
- Implement integration tests for critical workflows

### Data Management
- Store raw HTML in `data/raw_html/` with timestamps
- Process data to CSV/Excel in `data/processed/`
- Implement data validation and quality checks
- Use consistent naming conventions for output files
- Backup important data and models regularly

## Common Workflows

### Setting Up Development Environment
1. Install dependencies: `pip install -r requirements.txt`
2. Run system verification: `python verify_integrated_systems.py`
3. Setup Chrome profile: `python enhanced_chrome_profile_setup.py`
4. Train initial model: `python train_model_orchestrator.py`

### Adding New E-commerce Sites
1. Add site configuration to `config/enhanced_training_templates.yaml`
2. Implement site-specific selectors and patterns
3. Add extraction logic to scraping orchestrator
4. Test with small dataset and validate results
5. Update documentation and configuration examples

### Debugging and Monitoring
1. Use continuous bug scanner: `python continuous_bug_scanner.py`
2. Check logs in `logs/` directory for errors
3. Monitor system health with integrated dashboard
4. Validate configurations with YAML parsers
5. Test browser functionality with profile setup

### Production Deployment
1. Use headless mode for all browser operations
2. Configure batch processing with `scraping_config.json`
3. Set up monitoring and alerting systems
4. Implement data backup and recovery procedures
5. Monitor performance metrics and optimize as needed

## Troubleshooting

### Common Issues
- **BrowserManager headless error**: Ensure `headless` parameter is included in initialization
- **YAML syntax errors**: Validate configuration files with YAML parsers
- **Import errors**: Check Python path and module dependencies
- **Memory issues**: Implement browser cache clearing and connection management
- **Site structure changes**: Update selectors in YAML templates

### Debug Mode
- Enable verbose logging in `config/analyzer_config.yaml`
- Use `debug: verbose: true` for detailed output
- Save feature extraction data for analysis
- Monitor extraction times and performance metrics

### Performance Issues
- Check for large Python files (>500KB) that may impact performance
- Monitor scan times and optimize algorithms
- Use profiling tools for bottleneck identification
- Implement caching for frequently accessed data

## Security Considerations

### Credential Management
- Store credentials in encrypted JSON files
- Use environment variables for sensitive data
- Implement secure session management
- Rotate credentials regularly
- Never commit credentials to version control

### Browser Security
- Use anti-detection measures in browser setup
- Rotate user agents and browser fingerprints
- Implement proxy rotation if needed
- Monitor for detection and blocking
- Use secure profile storage
